# ISO 20022 Integration

SCSE is designed to be "Network Agnostic." While it settles on a Blockchain, it communicates using global standards to ensure compatibility with existing Core Banking Systems (CBS).

## Supported Message Types

| ISO Message | Description | SCSE Equivalent |
| :--- | :--- | :--- |
| **pacs.008** | Customer Credit Transfer | `PaymentInstruction` |
| **camt.053** | Bank-to-Customer Statement | `Statement` (Planned) |

## Mapping Specification

The SCSE `PaymentInstruction` is mapped to `pacs.008.001.08` as follows:

| SCSE Field | ISO 20022 Path | Notes |
| :--- | :--- | :--- |
| `id` | `GrpHdr/MsgId` | Unique Message ID |
| `timestamp` | `GrpHdr/CreDtTm` | Creation Date Time |
| `amount` | `TtlIntrBkSttlmAmt` | Total Settlement Amount |
| `debtorAgent` | `Dbtr/FnInstnId/BICFI` | Debtor Bank BIC |
| `creditorAgent` | `Cdtr/FnInstnId/BICFI` | Creditor Bank BIC |
| `instructionId` | `CdtTrfTxInf/PmtId/EndToEndId` | End-to-End Reference |

## Export Workflow

In the **Dashboard**, users can export any processed transaction:
1.  Locate the transaction in the **Ledger**.
2.  Click the **Export XML (`< >`)** button.
3.  The system generates the XML in real-time.
4.  User can **Copy** or **Download** the `.xml` file for processing in SWIFT Alliance Access or similar gateways.
